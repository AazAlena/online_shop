Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

## Ссылка на опубликованный проект

https://github.com/AazAlena/online_shop.git

## Структура проекта

```
- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.
- `sitemap.xml` — простая карта сайта;
```

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Реализованные элементы интерфейса

- шапка сайта с липким позиционированием (`position: sticky`);
- навигация по страницам и якорям;
- hero-блок с декоративными элементами (blob);
- хлебные крошки на внутренних страницах;
- карточки товаров с бейджами («Хит», «−20%», «Новинка»);
- кнопки заказа в карточках товаров;
- модальное окно `<dialog>` с формой заявки;
- поля формы: имя и e-mail (скрытое поле с товаром);
- базовая HTML-валидация (`required`, `type="email"`);
- JS-обработка формы и подсветка ошибочных полей;
- сообщение об успешной отправке.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox — основное меню, шапка, карточки товаров, hero, действия формы;
- CSS Grid — сетка карточек товаров, страница каталога с фильтрами и списком;
- адаптивность на `clamp()` для заголовка hero.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — общий блок раздела;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `catalog-products` — список товаров в каталоге;
- `filters-form` — форма фильтров;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `aside-info` — информационный блок;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка (`button--primary`, `button--secondary`).
